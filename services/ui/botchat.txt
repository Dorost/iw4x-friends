# What the bots say in the game chat (botchat.gsc). The game server reads this file at the start
# of every match: edit it and deploy. It started as all of Bot Warfare's own English lines (the
# bot mod, maps/mp/bots/_bot_chat.gsc), with the same moments and chances. At most 64 KB.
#
# [moment] 5%   starts the lines of a moment, with the chance (0-100) that a bot says one of them
#               then (10% when there's no number). One line of the section is picked at random.
#               Delete a whole section and the bots say nothing at that moment.
# Lines starting with # are notes, empty lines don't count. Color codes like ^1 work in lines.
#
# Filled in when said:
#   {color}      a random color for the text after it
#   {name}       the other player of the moment: who the bot killed, who killed it, ...
#   {map}        the map
#   {weapon}     a weapon (the one that killed, the grenade thrown, ...)
#   {mystreak}   the bot's kill streak        {theirstreak}  the other player's kill streak
#   {mydeaths}   the bot's deaths in a row    {theirdeaths}  the other player's deaths in a row
#   {random}     a random player in the match
#   {winner} {loser}  the best and the worst score of the match
#   {team}       the bot's team (allies or axis)
#   {seconds}    how long it camps or follows someone
#   {crate}      what's in the care package
#   {wasd}       random wasd letters
# A line with a {...} the moment doesn't have is never said: {weapon} only where the notes
# above a section name it.
#
# A line that starts with (something) is said only when that applies, e.g. (best) in [end won]
# only by the bot with the best score. Which ones there are is in the notes above each section.
